# Java-final-project

## 功能
簽到激勵
進階番茄鐘 / 正計時與倒數：支援傳統的 25/5 分鐘循環，或讓使用者自訂結構（例如：專注 50 分鐘、休息 10 分鐘）。
環境音伴讀（白噪音）：內建下雨聲、咖啡廳、篝火、甚至程式碼敲擊聲，幫助使用者快速進入「心流（Flow）」狀態。
待辦清單（To-Do List）與看板
階段性里程碑：設定長遠目標（例如：7 月底前讀完某本厚重教材），系統會自動倒數並推算每日應達成的最低進度。

熱點圖與時數統計：仿照 GitHub Contribution Graph 的「讀書格子」，書讀得越久，當天的格子顏色就越深；並提供日、週、月的圓餅圖，分析各科目的時間分配。

虛擬自習室（如 YPT 模式）：可以加入或創建小隊，即時看到目前有誰在線上、對方讀了多久。(加入DC畫面共享?)
喚醒隊友：若看到夥伴偷懶沒上線，可以點擊「拍一拍」或發送提醒，互相督促。
